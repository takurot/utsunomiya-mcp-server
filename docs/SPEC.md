# 機能仕様書: Utsunomiya Open Data MCP Server

## 1. プロジェクト概要

### 1.1 目的

宇都宮市オープンデータライブラリのデータを、Claude Desktopや他のMCP対応AIエージェントから自然言語で検索・取得・分析できるようにする。

### 1.2 アーキテクチャ構成

Web APIが存在しないため、**「カタログ方式」**を採用します。事前に有用なデータのURLを定義ファイル（`catalog.json`）に登録しておき、MCPサーバーがそれを読み込んで処理します。

```mermaid
[AI Agent (Claude)] <--> [MCP Protocol] <--> [MCP Server (Python)] <--> [宇都宮市公式サイト (CSV/Excel)]

```

---

## 2. 提供するツール (Tools)

AIモデルが呼び出し可能な3つの主要関数を定義します。

### ツール1: `list_datasets`

* **概要:** 利用可能な宇都宮市のデータセット一覧を返す。
* **引数:** なし（または `category` でフィルタリング）
* **戻り値:** データセットID、名称、説明、カテゴリのリスト。
* **ユースケース:** AIが「宇都宮市のどんなデータが使えるの？」と聞かれた時に使用。

### ツール2: `get_dataset_schema`

* **概要:** 特定のデータセットのカラム構造（ヘッダー情報）とサンプルデータ（最初の3行）を返す。
* **引数:**
* `dataset_id` (string): `list_datasets` で取得したID


* **戻り値:** カラム名リスト、データ型（推測）、行数、サンプルデータ。
* **ユースケース:** AIが分析コードを書く前に、データの構造を理解するために使用。

### ツール3: `query_dataset`

* **概要:** データセットの中身を取得する。全件取得またはSQLライクなフィルタリングを行う。
* **引数:**
* `dataset_id` (string): 対象のデータID
* `limit` (integer, optional): 取得行数（デフォルト: 100行 ※トークン節約のため）
* `filter_column` (string, optional): フィルタリング対象のカラム名
* `filter_value` (string, optional): 検索キーワード


* **戻り値:** JSON形式のデータ配列。
* **ユースケース:** 「宇都宮市の人口データを教えて」「〇〇地区の避難所リストを出して」という指示に対してデータを返す。

## 3. 内部処理ロジック (Backend Logic)

### 3.1 データカタログ管理 (`catalog.json`)

URLが変更されるリスクがあるため、ハードコードせず外部JSONで管理します。

```json
{
  "datasets": [
    {
      "id": "population_2024",
      "name": "町丁別世帯数及び人口",
      "url": "https://www.city.utsunomiya.tochigi.jp/.../jinko_r06.csv",
      "format": "csv",
      "encoding": "shift_jis",
      "description": "宇都宮市の各町丁ごとの人口と世帯数データ"
    },
    {
      "id": "evacuation_sites",
      "name": "指定緊急避難場所",
      "url": "https://www.city.utsunomiya.tochigi.jp/.../hinan.csv",
      "format": "csv",
      "encoding": "cp932",
      "description": "災害時の避難場所リスト、住所、対応災害種別"
    }
  ]
}

```

### 3.2 データ取得とキャッシュ (Fetcher & Cache)

* **Pandas利用:** データの取得と解析には Pythonの `pandas` を使用します。
* **エンコーディング対応:** `Shift-JIS`、`CP932`、`UTF-8` を自動判別または設定ファイルに従ってデコードします。
* **キャッシング (重要):** 毎回宇都宮市のサーバーにアクセスすると負荷がかかり、レスポンスも遅くなるため、一度取得したデータは一時フォルダ（`./cache/`）に保存し、一定時間（例: 24時間）は再利用するロジックを実装します。

### 3.3 データ整形 (Formatter)

* **欠損値処理:** `NaN` は `null` または空文字に変換してJSON化します。
* **サイズ制限:** AIのコンテキストウィンドウを溢れさせないため、1回のリクエストで返す最大文字数や行数にリミットを設けます（トークンオーバー防止）。

## 4. 技術スタック要件

* **言語:** Python 3.10+
* **フレームワーク:**
* `mcp` (Model Context Protocol SDK) または `fastmcp` (より簡易な実装用)


* **ライブラリ:**
* `pandas` (データ処理)
* `requests` (ファイルダウンロード)
* `chardet` (文字コード判定 ※必要であれば)

## 5. エラーハンドリング仕様

| エラー状況 | AIへの返答メッセージ例 |
| --- | --- |
| **URLリンク切れ** | 「指定されたデータセットのURLが無効になっています（404 Not Found）。管理者にカタログの更新を依頼してください。」 |
| **文字化け** | 「データのエンコーディング読み取りに失敗しました。Shift-JIS以外が含まれている可能性があります。」 |
| **データ過多** | 「データ量が多すぎて一度に表示できません。`limit`引数を小さくするか、フィルタ条件を追加して再検索してください。」 |

## 6. 開発ステップ

この仕様書に基づき、以下の順序で開発を進めることを推奨します。

1. **環境構築:** `uv` や `pip` でMCPプロジェクトを作成。
2. **カタログ作成:** 宇都宮市のサイトからテスト用に2〜3個のCSV URLを拾い、`catalog.json` を作成。
3. **Core実装:** PandasでURLからCSVを読み込み、JSONで返す関数を作る。
4. **MCP化:** 上記関数を `@mcp.tool` デコレータでラップする。
5. **接続テスト:** Claude Desktopの設定ファイルに記述し、実際に会話して動作確認。
